# Token use: 1.2.2 against 1.3.0 (13 November 2026)

One full scan of the same production FileMaker Server (82 ports, 215 MB of logs, 288 addresses), the same
prompt, in headless Claude Code on Sonnet (`claude -p --model claude-sonnet-5-5`), with the
installed copy of the skill turned off and each version loaded from a project folder. The prompt
gave the intake answers, skipped the server settings and file audit, and said not to ask
questions, so both runs went straight from scan to report.

| | 1.2.2 | 1.3.0 first build | 1.3.0 as released |
|---|---|---|---|
| Turns | 42 | 23 | **15** |
| Cost-equivalent (USD) | 1.78 | 1.12 | **0.81** (−55%) |
| Context written (cache write) | 173,531 | 85,902 | **66,389** (−62%) |
| Context re-read (cache read) | 1,374,760 | 1,091,973 | **682,788** (−50%) |
| Output tokens | 21,974 | 18,563 | **13,486** (−39%) |
| Minutes | 4.5 | about 4 | about 4 |

## What changed between the 1.3.0 builds

The first build's turn-by-turn record showed five turns lost to the scan folder's path (Claude
ran the scan from inside the skill folder, then looked for its output elsewhere), and four turns
reading `exposure.txt` and `services.json` because the summary didn't carry the certificate, TLS
and web path results. The released build prints the scan folder's full path, puts what the
internet sees in the summary, keeps `findings.json` to one finding per line with the wording once
per code (127 KB to 63 KB), and tells Claude to grep the saved files rather than open them.

## What the reports found

Both runs wrote the report in the skill's format, with the same sections and the same five
addresses to confirm. 1.2.2 called the result "Attempted attack"; both 1.3.0 runs said "Possible
compromise, not yet confirmed", which matches a separate, model-free scan of the same server made
with the same checks. 1.3.0's report had more rows (16 against 12) because the summary lists every kind of
finding.

## The floor

Every turn starts with about 39,000 tokens of context before the skill does anything: Claude
Code's own instructions and the tools of every plugin and MCP server installed on the Mac. In the
released run that floor is about 585,000 of the 683,000 tokens re-read. Fewer turns is now the
main lever; a Mac with fewer plugins and connectors turned on pays less per turn.

Not measured: Claude Desktop and Claude.ai, where the scripts run on the user's side and the
summary is pasted back, and Opus.
